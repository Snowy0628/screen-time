# 屏幕使用时间 · 安装说明

一个常驻后台、记录电脑使用时长的小工具，界面风格类似手机的「屏幕使用时间」。

---

## 一、怎么安装

1. 把压缩包**完整解压**到任意文件夹（不要直接在压缩包里双击运行）。
2. 在解压出来的文件夹里，**双击 `安装.exe`**。
3. 安装程序会自动完成：结束旧实例 → 复制文件 → 修复文件属性 → 建快捷方式 → 设置开机自启 → 启动并自检。
4. 看到绿色的「安装完成，托盘图标已注册成功」就 OK 了。

> ⚠️ **一定要在「文件资源管理器」里双击 `安装.exe`。**
> 不要从命令行、PowerShell、或某些带沙箱的软件里启动它。
> 否则安装程序会以「低完整性」运行，无法修复文件属性，托盘图标会失效。
> 安装程序检测到这种情况会主动提示你。

安装位置（不需要管理员权限）：

| 内容 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\ScreenTimeApp\` |
| 数据 | `%LOCALAPPDATA%\ScreenTime\` |

---

## 二、托盘图标在哪

装好后，程序常驻在**任务栏右下角的通知区域**。

**Windows 11 默认把新图标折叠起来**，所以第一次可能看不到：

1. 点任务栏右下角的 **`^`** 箭头（在时钟左边），展开「显示隐藏的图标」面板；
2. 找到那个**蓝紫色时钟图标**；
3. 用鼠标把它**拖到任务栏上**，以后就常驻显示了。

托盘图标的功能：

| 操作 | 效果 |
|---|---|
| 左键双击 | 打开主界面 |
| 右键 | 菜单：打开主界面 / 暂停记录 / 关闭窗口行为 / 打开数据目录 / 查看日志 / 退出 |

---

## 三、怎么用

打开主界面后：

- **顶栏**：`日` / `周` / `月` 切换统计范围；右上角是主题切换和设置。
- **四张概览卡**：屏幕总时长、真正使用时长、熄屏/锁屏/睡眠时长、最常使用的应用。
- **全天时间轴**：按真实状态着色（前台使用 / 空闲 / 锁屏 / 熄屏），悬停可看分段详情。
- **分时应用分布**：每小时一根柱子，柱高 = 该小时前台使用时长，柱顶显示该小时用得最多的应用图标。
- **应用使用排行**：每个应用占比，并与昨天（周/月视图则与上一周期）对比。

**设置面板**（顶栏齿轮图标）可调：空闲判定阈值、数据写入间隔、界面动效、启动行为、排行对比开关、关闭窗口行为。

---

## 四、数据说明

- 只记录**前台窗口所属的应用名称与时长**，**不记录窗口标题、不记录键盘输入内容**。
- 数据全部保存在本机 `%LOCALAPPDATA%\ScreenTime\`，**不联网、不上传**。
- 数据库是标准 SQLite（`usage.db`），可用任何 SQLite 工具查看。
- 想清空历史：关掉程序，删除 `usage.db` 即可。

---

## 五、卸载

1. 托盘右键 → 退出；
2. 删除这两个文件夹：
   - `%LOCALAPPDATA%\ScreenTimeApp\`
   - `%LOCALAPPDATA%\ScreenTime\`
3. 删除桌面快捷方式和启动文件夹里的 `屏幕使用时间.lnk`
   （启动文件夹：按 `Win+R` 输入 `shell:startup` 回车）。

## 六、常见问题

**Q：托盘里找不到图标？**
点 `^` 箭头展开隐藏图标面板找找。如果确实没有，请看下面「安装时的注意事项」——多半是安装程序被以受限方式启动了。

**Q：安装时提示「本安装程序正以低完整性运行」？**
说明你是从命令行/沙箱里启动的。关掉窗口，改在**文件资源管理器**里双击 `安装.exe`。

**Q：主界面关了，程序还在跑吗？**
在。关闭窗口的默认行为是「每次询问」，可以选择「最小化到托盘」或「彻底退出」，
也可以勾选「记住我的选择」。随时可在托盘右键菜单或设置面板里改回来。

**Q：窗口关掉后想再打开？**
双击桌面的「屏幕使用时间」快捷方式；或者双击托盘图标。

**Q：会不会记录我在看什么网页/文档？**
不会。只记录应用名称和时长，不记录任何窗口标题或内容。

## 七、给开发者的备注

安装包里那个 `安装.exe` 除了修复文件属性、建快捷方式之外没有别的作用；
程序本体在 `app\` 子文件夹里，可以直接运行 `app\ScreenTime.App.exe`。

**关于「低完整性」这件事**（这是本项目踩过的最深的坑，记下来避免重复）：

Windows 有强制完整性控制（MIC）。如果文件被打了 `Mandatory Label\Low` 标签，
**从该文件启动的进程也会被降为低完整性**，而低完整性进程：

- 被禁止向中完整性的 `explorer.exe` 发窗口消息 → `Shell_NotifyIcon` 返回「拒绝访问」→ **托盘图标永远注册不上**；
- 无法写入 `%LOCALAPPDATA%` → 只能降级到便携模式。

这在「把程序放在桌面/从受限终端运行」时都会发生。所以安装程序必须：

1. 把程序复制到没有该标签的目录（`%LOCALAPPDATA%`）；
2. **逐个文件**执行 `icacls "<file>" /setintegritylevel Medium`。

注意两个坑：

- 不能用 `icacls /T /C /setintegritylevel (OI)(CI)Medium`——**对文件无效**（文件仍是 Low），
  而且退出码还是 0，看起来像成功了；
- 进程**只能把标签设为不高于自身完整性的级别**，所以安装程序本身必须是中完整性。

`安装.exe` 会检测自身完整性并在受限运行时给出明确提示，可用 `--dry-run` 只复制不建快捷方式，
用 `--dir <路径>` 指定安装到别处。
