# 屏幕使用时间 v1.0

**功能齐备的正式版**

## 功能

- 单日视图：概览卡、24 小时时间轴、分时应用柱状图、应用排行
- 周 / 月视图：每日柱状图、月历热力图、周期对比排行
- 按应用图标主色为图表上色
- 全屏应用不算空闲、横轴起点可配置、时间轴可切 30 分 / 1 小时 / 3 小时分格
- 时长格式统一（`1时0分` 而非 `1h 0m`）
- 深色模式，标题栏与滚动条跟随主题
- 新增卸载程序与开始菜单卸载入口

## 修复

- 程序把自己识别成"未知"
- 周 / 月视图点一下就卡死（`MondayOffset` 自递归导致 `StackOverflowException`，
  进程直接终止）
