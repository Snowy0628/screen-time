# 屏幕使用时间 v1.7

## 新增：主题色自定义

- 「设置 → 外观 → 主题色」：6 个莫兰迪灰调预设 + 十六进制色号输入框
- 预设：洛天依蓝 `#66CCFF`、雾霾蓝、鼠尾草绿、陶土粉、灰紫、燕麦棕
- 色号支持 `#66CCFF` 与 `66CCFF`，输入时实时预览并校验
- 默认方案保持原有蓝紫渐变；选预设或自定义色则改为**纯色**
- 生效范围：顶栏 Logo、总时长卡片、日/周/月分段按钮、热力图、图表强调色
- 涨跌红绿是语义色（用时长变多算坏消息），不跟主题色变

实现上很轻：界面所有强调色本来就走 `DynamicResource`，集中在主题字典的两个令牌
（`AccentBrush` 纯色、`HeroBrush` 渐变），换色 = 运行时替换这两个资源。

## 新增：背景图

- 选择图片 / 清除 / 不透明度滑块（0–100%）
- 有背景图时卡片自动变半透明（约 80%），让图片透出来
- 用**带 alpha 的同色画刷**而不是元素 `Opacity` —— 后者会把文字一起变淡
- 半透明覆盖只作用于主内容区，设置面板保持不透明
- 图片按窗口宽度解码，4K 大图不会每帧缩放

## 图标全部改为黑白简约风格，并跟随深浅色

- 一条统一规则：**浅色模式白底黑线，深色模式黑底白线**
- 覆盖三处并保持一致：程序图标（exe 内嵌 + 标题栏 + 任务栏）、
  界面 Logo（顶栏与设置面板标题）、托盘图标
- 小尺寸简化：40px 以下只画圆环 + 一根指针，否则线条糊成一团
- 标题栏/任务栏图标用 `WM_SETICON` 运行时替换，随深浅色实时切换
- exe 内嵌图标固定浅色模式版（资源管理器取文件资源，运行时改不了）

## 应用分类新增「游戏」

- 关键字表补入实际出现过的进程名：`Client-Win64-Shipping`（虚幻引擎游戏主进程）、
  `launcher_main`、`KRSDKExternal`、`uu`（UU 加速器）等
- 「游戏」排在「娱乐」之前，否则 `steam` 这类两边都沾的会被娱乐抢走

## 这一版踩到的坑（都记在代码注释里了）

1. `Panel.ZIndex` 是**同级比较**。给内容区加 `ZIndex=2` 让背景图正常之后，
   设置面板仍是默认的 0，于是主内容画到了面板上面 —— 表现为"图表穿透面板"。
2. `FrameworkElementFactory` 手搓 `ControlTemplate` 时，里面的 `ContentPresenter`
   **不会**自动接到按钮的 `Content`。漏了 TemplateBinding 就只画出按钮外框、
   里面空白。这一版最终改用 `Border` + 鼠标事件，绕开模板查找这一层。
3. 长按 `BitmapImage` 会锁住文件；用 `CacheOption.OnLoad` 读完即释放，
   用户才能随便删换背景图。
4. `WM_SETICON` 只把**句柄**交给 Windows，系统不复制图标数据。写成
   `using var icon = new Icon(...)`，方法一返回就 Dispose、句柄失效，
   标题栏图标直接变空白 —— 不报错，只表现为"图标不见了"。
5. 换 Logo 时要**全局搜一遍**旧实现。这一版只改了顶栏，漏掉了设置面板标题里
   那个一样的渐变方块 + 齿轮字形，结果同一界面上一个新一个旧。
