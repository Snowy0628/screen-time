# 屏幕使用时间 v1.3

## 修复：程序运行约 90 秒后自动关闭

- 现象：挂到托盘没多久，程序自己就没了；`app.log` 里没有任何退出记录，
  `crash.log` 也不生成，看起来像"被杀后台"
- 根因：判断"是否有全屏应用"用的是 `SHQueryUserNotificationState()`，
  它被放在每秒执行一次的采集循环里，运行约 90 秒后抛 `AccessViolationException`
  （事件日志 `Application Error 0xc0000005`）。
  **这类异常在 .NET 里无法被 catch 捕获** —— CLR 有意让进程直接终止
- 修法：改用窗口几何判定（`GetForegroundWindow` / `GetWindowRect` /
  `MonitorFromWindow` / `GetMonitorInfoW`），只依赖稳定的 API
- 实测：托盘 + 全屏看视频连续 15 分钟，零崩溃、心跳零延迟、内存稳定

## 新增诊断手段

- 心跳文件（`heartbeat.txt`，每秒写一次戳）：区分"从没启动过"与
  "启动了但中途异常死亡" —— 后者不会留下任何日志
- 启动记录（`boot-history.log`）：每次启动追加一行，含时间戳、PID、
  命令行参数与"开机已过多少秒"，可直接判断自启是否生效
- `tools/monitor-run.ps1`：一条命令做存活监控 + 崩溃取证
