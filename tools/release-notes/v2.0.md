# 屏幕使用时间 v2.0

> 首个 v2.0 构建。**请优先使用 [v2.0-pro](https://github.com/Snowy0628/screen-time/releases/tag/v2.0-pro)** —— 它是本版的修订版，修掉了本版遗留的若干显示问题。

## 新增：应用分类

- 顶栏新增分类入口（日/周/月 与 深浅色按钮之间）
- **统计在上**：圆环图 + 图例，显示各分类时长与占比
- **自定义在下**：新建 / 删除自定义分类、逐个应用改分类、搜索
- 默认 10 类：开发 / 浏览器 / 设计 / 办公 / 沟通 / 游戏 / 娱乐 / 系统 / 自身 / 其他
- 判定优先级 **手动设定 > 关键字推断 > 其他**；手动按完整路径匹配，
  不同目录下的同名 exe 可分别归类
- 每行标注「自动识别」/「已手动指定」
- 删除自定义分类会连带清掉指着它的手动设定，避免孤儿数据
- 自定义分类名存在 `settings.json` 而非数据库：卸载时数据库可能被清空，
  但"我起过哪些分类名"属于配置

## 图表与图标

- 柱状图刻度线由实线改为虚线，标签加底色避免线穿过文字
- 图标统一为 Segoe MDL2 单色字形
- 圆环中心文字改固定白色 + 柔和阴影

## 自检

新增 `--catest`，24 项断言。
