# 屏幕使用时间 v2.0-pro

## 新增：应用分类

- 顶栏新增分类入口（日/周/月 与 深浅色按钮之间）
- **统计在上**：圆环图 + 图例，显示各分类时长与占比；中间显示合计时长
- **自定义在下**：新建 / 删除自定义分类、逐个应用改分类、搜索
- 默认 10 类：开发 / 浏览器 / 设计 / 办公 / 沟通 / 游戏 / 娱乐 / 系统 / 自身 / 其他
- 判定优先级 **手动设定 > 关键字推断 > 其他**；手动按完整路径匹配，
  不同目录下的同名 exe 可分别归类
- 每行标注「自动识别」/「已手动指定」；改完饼图立即重算
- 删除自定义分类会连带清掉指着它的手动设定，避免孤儿数据
- 自定义分类名存在 `settings.json` 而非数据库：卸载时数据库可能被清空，
  但"我起过哪些分类名"属于配置

## 统计周期可切（日 / 周 / 月）

- 面板标题栏右侧一组切换，与主界面**共用同一套口径**（周从周一开始、月是自然月）
- 切换周期时**下方应用列表一起切**，列表里的时长同样按该周期算
- 打开面板时周期跟随主界面当前选择；面板里切换不改主界面

## 圆环图扫出动画

- 切换周期时扇区从 12 点方向顺时针"扫"出来（620ms 缓出），而不是逐个淡入
- 实现是引入一个"扫出进度"（0→1），每个扇区按自己的角度区间与进度取交集，
  因此无论一个大扇区还是十几个小扇区，看起来都是连续扫过一整圈
- 动效关闭时直接落到完整状态，不留半截

## 分类颜色自定义

- 每个应用行尾有**色点**，点它在旁边弹出取色器（10 个莫兰迪预设 + 色号输入）
- **颜色是分类的属性，不是应用的属性**：改一个色点会同时改变该分类下所有应用
  的色点、以及饼图里对应那一块
- 只造一个共享弹窗而不是每行一个：列表可能有上百行，同一时刻也只可能改一个颜色
- **试色时不重建应用列表**，否则每点一个颜色列表就跳一次、还要重新定位

## 状态圆点

- 修掉重复画点：`LiveStatusText` 里原本手写了一个 `●` 字符，而圆点已由
  `LiveDot` 元素画出，于是屏幕上出现两个点（一个真圆点 + 一个灰色字符）
- 加上**呼吸灯**：不透明度 1.00 ⇄ 0.30、周期 1.6 秒、正弦缓动
- 跟随「启用界面动效」开关，关掉后立刻停在静止圆点

## 界面细节

- 柱状图刻度线改为**虚线**，并给刻度标签加卡片同色底色
  （线原本从文字中间穿过，看起来像删除线）
- 修掉 **WPF 焦点虚线框**（图表容器拿到焦点时系统画的那圈虚线）
- 顶栏状态框圆角从全圆胶囊改为 10，与旁边的「日/周/月」分段控件一致
- 图标全部改为 Segoe MDL2 单色字形；圆环中心文字改固定白色 + 柔和阴影
- 柱状图说明文字精简（原来把刻度、读法、配色、交互全塞在一行）

## 修复：最大化窗口被永久算作「正在使用」

- 现象：窗口最大化后挂着不动，既没放视频也没碰键鼠，却一直记为「使用中」
- 根因：v1.4 为了修"窗口化看视频被记成空闲"，把全屏判据放宽成
  **覆盖工作区（最大化）或覆盖整个显示器（真全屏）都算活跃**。
  但**最大化窗口和"人是否在用"毫无关系**——它只是个窗口摆法。
  判据包含它，等于给任何最大化应用开了永久豁免：
  只要窗口最大化，空闲阈值就永远不生效
- 而 v1.4 想解决的那个场景，**v1.6 的媒体检测已经覆盖得更准**
  （查系统媒体会话的真实播放状态，窗口化 / 最大化 / 全屏都有效）
- 修法：全屏判据**只认真全屏**（覆盖整个显示器）。现在的分工是清楚的：

  | 场景 | 由谁负责 |
  |---|---|
  | 看视频（任何窗口模式） | 媒体检测 |
  | 沉浸式使用（F11 真全屏） | 窗口几何 |

  两者不再重叠，也就没有"哪个说了算"的冲突
- 唯一取舍：无边框窗口化的游戏，若既没放媒体、又长时间不动键鼠/手柄，
  会被记为空闲。但那种情况本来就应该算空闲——挂机就是挂机

## 自检

新增 `--catest`，共 **39 项断言**，覆盖手动优先级、按路径匹配、删除连带清理、
默认分类保护、饼图占比之和为 100%、三种周期的日期区间、分类颜色覆盖与恢复。

`--idlecheck` 新增**真全屏判据自检**（合成数据，不依赖当前桌面状态）：

```
✓ 最大化窗口：不算活跃        ← 本次修复的回归点
✓ F11 真全屏：算活跃
✓ 普通窗口：不算活跃
✓ 差 3 像素贴边（超出容差）：不算活跃
✓ 副屏上的真全屏：算活跃
✓ 副屏窗口对主屏矩形：不算活跃
```

几何判断抽成纯函数 `WindowIsTrueFullscreen(窗口矩形, 显示器矩形)` 才做得到这一点。
理由是：**这个判据改错过两次，而两次的错误都只在真实窗口上才看得出来**——
靠肉眼看界面无法确认"最大化窗口到底算不算活跃"。

## 安装

1. 解压后双击 **`点这里安装.cmd`**
2. 默认安装到 `C:\ScreenTime`，可自定义目录
3. **请勿安装到桌面** —— 桌面文件带低完整性标签，会导致托盘图标失效，
   安装程序会拦截这类位置并说明原因
4. `安装.exe` 是安装程序本体；`点这里安装.cmd` 会先把文件复制到临时目录再启动它，
   这样即使压缩包被解压到桌面也能正常安装

## 升级

直接运行新版安装程序覆盖安装即可，使用记录与设置都会保留
（数据在 `%LOCALAPPDATA%\ScreenTime\`）。
